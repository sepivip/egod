# egod.space

Personal landing page for Beka Zakaidze.

## Deploy

Static single-file site. Drop `index.html` anywhere — GitHub Pages, Cloudflare Pages, Netlify, or any static host.

### GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **main** branch, root `/`
4. Your site is live

### Cloudflare Pages

1. Connect your GitHub repo in the Cloudflare dashboard
2. Build command: *(none)*
3. Output directory: `/`
